# AI Task Agent

Telegram-бот для управления задачами на естественном языке. AI-агент интерпретирует сообщения пользователя и вызывает инструменты для создания, просмотра и изменения задач.

Проект создан как практический MVP для изучения разработки AI-агентов и автоматизации процессов с помощью Python, LLM и n8n.

## Features

- Управление задачами через Telegram на естественном языке.
- Создание задач с датами и временем.
- Просмотр задач на сегодня и просроченных задач.
- Изменение существующих задач.
- Автоматические напоминания через Telegram.
- Планировщик напоминаний на базе n8n.
- Защита API с помощью токена.
- Хранение задач в PostgreSQL.

## Architecture

```text
Telegram
   |
   v
n8n — обработка сообщений и отправка напоминаний
   |
   v
FastAPI — API и AI-агент
   |
   +--> OpenRouter — доступ к LLM
   |
   +--> PostgreSQL — хранение задач
```

Основные компоненты:

- **Python / FastAPI** — API приложения.
- **AI agent** — интерпретация запросов и выбор инструментов.
- **OpenRouter** — доступ к языковой модели.
- **PostgreSQL** — хранение задач и данных напоминаний.
- **n8n** — интеграция с Telegram и периодическая проверка напоминаний.
- **Docker Compose** — запуск сервисов.

## Requirements

- Docker и Docker Compose.
- Telegram-бот, созданный через BotFather.
- API-ключ OpenRouter.
- Токен ngrok для внешнего доступа к n8n, если он требуется для настройки Telegram Trigger.

## Configuration

1. Создай локальный файл `.env` на основе `.env.example`:

   ```bash
   cp .env.example .env
   ```

2. Заполни необходимые переменные окружения:

   - `OPENROUTER_API_KEY` — API-ключ OpenRouter.
   - `DATABASE_URL` — строка подключения к PostgreSQL.
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
   - `API_TOKEN` — секретный токен для защиты API.
   - `NGROK_AUTHTOKEN` и связанные настройки ngrok — если используются.

3. Используй сильное случайное значение для `API_TOKEN`. Не добавляй `.env` в Git и не публикуй секреты.

## Run with Docker Compose

Собери и запусти сервисы:

```bash
docker compose up -d --build
```

Проверь состояние контейнеров:

```bash
docker compose ps
```

Проверь доступность API:

```bash
curl http://localhost:8000/health
```

Для просмотра логов приложения:

```bash
docker compose logs -f app
```

## Telegram and n8n

После запуска сервисов:

1. Открой n8n по адресу, настроенному в проекте.
2. Настрой Telegram credentials в n8n.
3. Настрой workflow обработки сообщений: Telegram Trigger → HTTP Request к `/chat` → Telegram Send Message.
4. Добавь заголовок `X-API-Token` с тем же значением, что и `API_TOKEN`, в HTTP Request к защищённым API-эндпоинтам.
5. Активируй workflow обработки сообщений.
6. Настрой и активируй workflow `Task Reminders`, который периодически получает ожидающие напоминания, отправляет их в Telegram и отмечает отправленные.

Точный внешний URL для Telegram webhook зависит от настроек ngrok и n8n.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/health` | Проверка доступности API |
| POST | `/chat` | Обработка сообщения пользователя AI-агентом |
| GET | `/reminders/pending` | Получение напоминаний, готовых к отправке |
| POST | `/reminders/{task_id}/sent` | Отметка напоминания как отправленного |

Эндпоинты приложения, кроме `/health`, требуют заголовок `X-API-Token`.

## Current scope

Это MVP, предназначенный для демонстрации взаимодействия AI-агента с инструментами, API, базой данных и внешними автоматизациями.

Возможные направления развития:

- журнал выполнения агента: запросы, вызванные инструменты, результаты, ошибки и стоимость;
- улучшение обработки дат и времени;
- расширение набора инструментов и сценариев управления задачами;
- автоматизированные тесты и мониторинг.
